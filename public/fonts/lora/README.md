# Lora Medium · subtitles

Lora, weight 500 upright, Google Fonts v37. Cyrillic and Latin WOFF2 subsets are served locally; the game makes no request to Google Fonts.

- Design and description: https://cyreal.org/fonts/lora/
- Source: https://github.com/google/fonts/tree/main/ofl/lora
- License: SIL Open Font License 1.1, included as `OFL.txt`.
- Retrieved 2026-11-17 from Google Fonts CSS API `https://fonts.googleapis.com/css2?family=Lora:wght@500&display=swap`.
- Cyrillic: `https://fonts.gstatic.com/s/lora/v37/0QI6MX1D_JOuGQbT0gvTJPa787wsuxJFkq1umA.woff2`
- Latin/punctuation: `https://fonts.gstatic.com/s/lora/v37/0QI6MX1D_JOuGQbT0gvTJPa787wsuxJBkq0.woff2`

Applied only to prologue captions. Medium upright gives the narration a book-like tone while retaining readable Cyrillic on small screens. CSS keeps a dark backing and shadow; sizes are 18–24 px, including 18 px in phone landscape. This is a design choice, not a user readability study. MP4 players choose their own subtitle font; the custom typography appears in the game's DOM captions.
