# Люми и дорога огней

Веб-игра DayEnglish для изучения английской грамматики через головоломки со словами. React, Phaser, TypeScript и Vite. Игра запускается самостоятельно или встраивается в DayEnglish через публичный SDK.

Реализованы первая глава об артиклях (12 эпизодов / 25 частей) и вторая глава о местоимениях, be, числе, отрицаниях и вопросах (20 эпизодов / 76 частей). Озвучка, музыка, изображения и липсинг поставляются готовыми файлами; API генерации во время игры не вызывается. Новые записи второй главы ещё проходят слуховую приёмку. Постоянное сохранение прогресса пока не подключено.

## Запуск

Нужны Node.js 24 и npm. Точные зависимости закреплены в package-lock.json; SDK включён в vendor/.

```sh
npm ci
npm run dev
```

Открыть http://localhost:5189. По умолчанию работает самостоятельный режим, .env не требуется. Публичные настройки интеграции перечислены в .env.example; секреты нельзя помещать в переменные VITE_*.

WASD/стрелки — шаг, Z/Backspace — отмена, Enter — применить фразу, Escape — меню. На телефоне доступны крестовина и свайпы; рекомендуется альбомная ориентация. В режиме разработки карта фонарей позволяет открыть любой реализованный эпизод через DEV-кнопку. В production этого перехода нет.

## Проверки и сборка

```sh
npm run check
npx playwright install chrome
npm run test:e2e
npm run build
npm run preview
```

check проверяет навыки, lint, формат, release tooling, unit-тесты, TypeScript и сборку. Браузерные тесты поднимают собственный сервер на 4289. Исторические A/B/C-прототипы диалогов проверяются только при наличии локальной папки docs/design/dialogue-prototypes; проверки игрового интерфейса от неё не зависят.

## Состав репозитория

- src/domain — учебные данные и чистая логика головоломки.
- src/game — Phaser, игровая сессия, звук и анимации.
- src/app — React-интерфейс.
- src/platform — интеграция через DayEnglish SDK.
- public — готовые игровые медиа, шрифты и лицензионные уведомления.
- tests и tests/fixtures — браузерные сценарии и фиксированные данные для проверки озвучки.
- scripts — проверки, подготовка релизов и инструменты авторинга.
- .agents/skills и AGENTS.md — правила разработки и навыки проекта.

.env, docs, skinBagNotes, MASTER_PLAN.md, UX-отчёты, исходники assets, локальные конфигурации, node_modules, dist и artifacts исключены через .gitignore. Они остаются на компьютере автора. Для запуска, сборки и основных проверок они не нужны. Скрипты генерации медиа требуют локальных исходников и соответствующих ключей; копирование репозитория само по себе не запускает генерацию и не расходует квоты.

Тестовые JSON в tests/fixtures — отдельные снимки ожидаемого текста, голосов и происхождения аудио. При утверждённом обновлении озвучки соответствующие снимки нужно обновлять осознанно; тесты не синтезируют звук и не используют ключи.

## GitHub и публикация

Push и pull request запускают проверки. Публикация игры выполняется только вручную через workflow_dispatch с deploy=true, разрешённой переменной YC_GAME_DEPLOY_ENABLED и настроенным окружением production. Push исходников сам по себе игру не публикует. Конфигурация релиза — release.config.example.json; локальные настройки и ключи не коммитятся.
